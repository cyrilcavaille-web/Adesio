ar2ed36

Convertit les accusés de réception (AR) de commande fournisseurs — PDF texte ou scannés — vers le fichier d'import Excalibur ED36, avec un contrôle de cohérence ligne à ligne avant tout import. Traitement entièrement dans le navigateur : rien n'est envoyé à un serveur.

01
Ingestion
Lecture du PDF, détection de la couche texte
02
Classification
Identification du fournisseur par empreinte texte
03
Extraction
Parseur dédié par fournisseur (ancres + regex)
04
Normalisation
Dates, conventions FR/EN, prix à l'unité
05
Contrôles
Champs obligatoires, PU × Qté = total, écart de délai
06
Export
Fichier Excel ED36 + journal de contrôle
1. Charger les AR fournisseurs
Dépose un ou plusieurs AR (PDF)
ou clique pour parcourir — EBV, ICAPE, Confidee, Polyrack, Duflot…

AR scanné sans couche texte (ex. Duflot, bon de commande retourné signé) : attache le JSON OCR correspondant sur sa ligne pour en extraire les postes.

Les librairies de lecture PDF / génération Excel n'ont pas pu se charger. Recharge la page ou réessaie plus tard.

Résultat

Exemple préchargé

ar2ed36 — Adesio. Lecture PDF (pdf.js) et export Excel (ExcelJS) exécutés localement dans le navigateur ; aucun fichier n'est transmis à un serveur. Les parseurs EBV / ICAPE / Confidee / Polyrack restent à valider sur des AR réels de ces fournisseurs.
